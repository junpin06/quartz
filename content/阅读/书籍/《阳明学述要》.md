# 《阳明学述要》笔记

# 一、宋学里留下来的几个问题

## 1.本体论——万物一体（周濂溪《太极图说》、张横渠《西铭》）

    - 问题：天地万物一体之理，应该格之外物？还是立之吾心？
    - 矛盾：周濂溪《太极图说》唯物，《通书》偏心性。张横渠《西铭》无阴阳五行，《正蒙》讲阴阳五行。

朱子认为，万物一体之理是外面的实在本体如此，并非吾心以意会之。（承周濂溪《太极图说》，张横渠《正蒙》精神）要证明这一说法，只有两条路：

    1. 格物，即凡天下之物而格之，以求至乎其极。
    2. 读书信古。

陆象山只说立心，说自立，自省自觉，心即理也，万物皆备于我。（与程颢明道相近）

## 2.修养论——变化气质（气质指躯体，宋儒意见，人生一切习惯，皆从躯体起）

    - 明道，遽忘其怒而观理之是非。
    - 伊川，克己可以治怒，明理可以治惧。
    - 变化气质只是要泯化小我，复归大我。

程门学决

    - 敬（敬是一种心理的态度，或活动。从反面说，则是中心没事，是心无所系，是心底里无潜隐，无躲闪；从正面说，则是循理，是敬。人心有所系是私，能循理便是公。）
        - 在静坐时“看未发之中”
        - 心不可有一事
        - 心要在腔子里（心无所系）
        - 庄静持守
    - 致知（知的工夫还在敬之上）
        - 学在知其所有，又在养其所有
        - 只须用敬，不知集义，却是都无事
        - 涵养需用敬，进学则在致知（程伊川）

 敬义夹持，明诚两进。——黄梨洲

朱陆分垒

- 朱子要人先泛观博览而后归之约，主张从致知一边下工夫。道问学
- 陆象山要先发明人之本心，而后使之博览，主张先从持守方面下工夫。尊德性

# 三、王学三变（从狷入狂再入中道）

**庄静持守**：居夷处困，悟格物致知之旨，圣人之学，吾性自足，不假外求。尽去枝叶，一意本院，以默坐澄心为学，有未发之中，始能有发而中节之和，视听言动，大率以收敛未主，发散是不得已。（心上功夫，要荡涤扫除，要无染着，无偏倚，要此心廓然，毫无滞留，这是宋明理学的真血脉） 狷

**致良知**：江右以后，专提致良知三字，默不假坐，心不待澄，不习不虑，出之自有天则。良知是未发之中，是中节之和。  狂

**知行合一**：知之真切笃实处即是行，行之明觉精察处即是知，无有二也。居越以后，所操益熟，所得益化，时时知是知非，时时无是无非。开口即得本心，更无假借凑泊，如赤日当空，而万象毕照。 中道

# 四、王学大纲

1. 良知
    1. 良知是天理昭明灵觉处，故良知即是天理
        1. 天理是一个分善别恶的总名，而善恶的标准推及本源，只在人心的自然灵觉处。
        2. 故天理只从人心上发，除却人心，不见天理。
    2. 良知，只是一个真诚恻怛
    3. 良知只是个是非之心，只是个好恶
    4. 良知之真诚恻怛以事亲便是孝，事兄便是悌，事君便是忠
    5. 心外无理，心外无事

人心即是天理，更不烦有所谓凑泊，也不烦有所谓工夫。

2.知行合一（敬）

    1. 未有知而不行者。知而不行，只是未知。
    2. 如恶恶臭，如好好色。
    3. 知行之不合一，只为有私欲隔了（承宋学传统）
    4. 知行是一物两端
    5. 知是行的主意，行是知的工夫。知是行之始，行是知之成
    6. 一念发动处，便即是行了，发动出有不善，就将这不善的念克到了，须要彻根彻底，不使那一念不善潜伏在胸中。（敬）

3.致良知（义）

    1. 致良知，即以致知格物之功，胜私复理，心之良知更无障碍，得以充塞流行。（义）
    2. 夫必有事焉只是集义，集义只是致良知。
    3. 随时就事上致其良知，便是格物
    4. 凡学问之事，一则诚，二则伪

4.诚意（敬）

    1. 诚意之说，自是圣门教人用功第一义。
    2. 惟天下之至诚，然后能立天下之大本。
    3. 圣人之学，只是一诚而已。
    4. 知行本体实只是一个“诚”，诚意之极，知行自见合一，便是真能好恶的良知。

5.谨独

    1. 只是一个工夫，无事时固是独知，有事时亦是独知、
    2. 人若不知于此独知之地用力，只在人所共知处用功，便是作伪。此独知处，便是诚的萌芽。
    3. 独知处，立诚。

6.立志

    1. 所谓困忘之病，亦只是志欠真切。今好色之人，未尝病于困忘，只是一真切耳。
    2. 持志如心痛，一心在痛上，岂有工夫说闲话，管闲事？
    3. 立志，勿忘勿助长
    4. 立志贵专一

讲王学的人，只要先辩一个真切为善之志，专一在此，更无别念挂带，便是良知栽根处。从此戒慎恐惧，从谨其独知处下手。别人不知，只我自知处，是谓独知。若能从独知处下工夫，久久自见意诚境界。意诚了，自得认识知行合一的本体。识得此体自会悟到自己的 良知。

7.事上磨练

    1. 心无体，以天地万物感应之是非为体。（本体论）
        1. 惟有事，乃有心与物可见
        2. 天地万物是一个灵明
        3. 没有我们的灵明就没有天地万物，离却天地万物，亦没有我们的灵明
    2. 磨练自己一心的喜怒哀乐
    3. 在危难非常时刻，更需事上磨练
    4. 省察是有事时存养，存养是无事时省察

事上磨练：不论有事无事，只是个必有事焉；只是个存天理，去人欲；只是要自己的喜怒哀乐，有一个未发之中，和发而中节之和。

天理在实践中，良知亦在实践中。天地万物与我一体亦在实践中。不实践，空言说，则到底无是处。

# 五、阳明的晚年思想

1.拔本塞源论

    1. 正面是天地万物一体之仁，反面是功利之私
    2. **人人分工而合德，人人平等自由，各还他一个天赋的才性之真，与本心的好恶之诚，而各成为一个圆满无缺之圣。**
    3. 论人类全体、论人生一切知识才能与事业、论人与人相处之异、论政治、经济、社会一切问题。
    4. 圣人之所以为圣，只是其心纯乎天理而无人欲之杂。为圣者，在纯乎天理而不在才力。
